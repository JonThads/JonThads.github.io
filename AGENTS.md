# AGENTS.md

Instructions for any AI coding agent (Codex, Claude, others) working in this
repository, a static GitHub Pages portfolio.

Follow, in full:

- [docs/workflow/claude-instructions.md](docs/workflow/claude-instructions.md)
- [docs/workflow/implementation-workflow.md](docs/workflow/implementation-workflow.md)

Summary: Conventional Branch (prefixed branches cut from `qa`, never work on
`main` or `qa` directly), Conventional Commits, Conventional Comments, Common
Changelog updated in the same change set, and no push/merge/PR/branch deletion
without the user's explicit go-ahead. Merging into `main` publishes the live
site.
