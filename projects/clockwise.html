Project overview

A web application that brings attendance, employee records, shift schedules, and leave requests into one place for employees, managers, and HR teams.

Key features

  • Employee records, departments, work groups, and shift assignments.
  • Clock-in and clock-out records, attendance reporting, and personalized dashboards.
  • Leave requests, approvals, leave types, and balance tracking.

Engineering & quality

The repository documents unit, integration, end-to-end, and accessibility testing, with axe-core and Python/FastAPI/Allure reporting. Docker provides the environment and GitHub Actions supports CI/CD.

Scope & ongoing work

Overtime and undertime calculations are marked as under development. Accessibility guidelines are applied where feasible; the repository documentation is not an independent WCAG certification.

Project summary based on the public repository documentation. See the repository for current implementation details.
