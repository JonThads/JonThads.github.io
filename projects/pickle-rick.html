Pickle-Rick

A two-sided pickleball platform for court management, player reservations, and Pasalo join requests.

ReactViteNode.jsExpressPostgreSQLDockerPostmanPlaywrightk6

Project overview

A portfolio and learning project combining an admin court-management system with player reservations. Built with AI-assisted, documentation-driven development using Claude Code and structured prompts.

Key features

  • Role-based player and admin accounts with JWT authentication.
  • Court pricing, inventory management, and automatic or manual booking approval.
  • Player reservations and Pasalo requests to join approved bookings.

Engineering & quality

The documented stack includes Postman API checks, Playwright/TypeScript end-to-end checks, k6 load testing, GitHub Actions pipelines, and Prometheus/Grafana monitoring. The frontend uses React/Vite and the backend uses Express with raw PostgreSQL queries.

Scope & ongoing work

Player shop/checkout and the analytics dashboard remain in progress. Python/FastAPI analytics is planned in the repository; it is not presented here as a completed feature.
