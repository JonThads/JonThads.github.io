A self-hosted service for asking natural-language questions about repository documentation, with cited sources.

Project overview

A retrieval-augmented generation service that ingests repository documentation, embeds text locally, retrieves relevant chunks from pgvector, and generates answers through a local Ollama model.

Key features

  • Ingest local or Git-hosted Markdown documentation and replace a repository corpus on re-ingestion.
  • Query documentation with source chunks, similarity scores, and stage timings; stream generated answers through server-sent events.
  • Manage ingested repositories, with optional API-key authentication and per-client rate limiting.

Engineering & quality

Prometheus and Grafana expose retrieval, embedding, generation, and error metrics. DeepEval evaluation scaffolding scores faithfulness and relevance using Ollama; its placeholder expected answers need a real project-specific test set.

Scope & ongoing work

Retrieval is vector-only, without hybrid search or reranking. Chunking uses paragraph-based size limits. LangChain/LangGraph refactoring and Kubernetes deployment are stretch plans, not implemented features.
