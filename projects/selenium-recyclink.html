Project Overview

This automated testing utilizing the Page Object Model (POM) Organization Pattern was developed using Selenium and Pytest to showcase my skills using my own project web app for my Postgraduate Studies - RecycLink

Technologies & Tools

Selenium WebDriver
A browser automation framework used to simulate user actions and perform end-to-end web testing
Pytest
A lightweight yet powerful testing framework for Python that simplifies writing, organizing, and running automated tests
WebDriver Manager
A Python library that automatically handles browser driver installation and updates (e.g., ChromeDriver)

Key Features

  • Integration with test frameworks like Pytest
  • Simple test syntax and fixtures
  • Automatically detects and downloads compatible driver versions

Challenges & Solutions

Challenge: Selenium required manual ChromeDriver updates
Solution: By integrating WebDriver Manager, your setup now automatically detects and updates the correct ChromeDriver version — preventing version mismatch errors and reducing maintenance effort.
