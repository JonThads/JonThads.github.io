Tokenomics MCP

An MCP server for counting prompt tokens and estimating model API costs inside Claude Code CLI.

PythonMCP SDKtiktokenAnthropic SDKpytestDockerGitHub ActionsGHCR

Project overview

A stdio-based MCP server that exposes token counting and cost-estimation tools to a chat client, without a separate browser-based counter or HTTP server.

Key features

  • Count tokens for a selected model.
  • Estimate input and expected output costs and compare supported models.
  • Report the counting method and pricing verification date so estimates can be interpreted.

Engineering & quality

Pure pricing logic is covered by pytest with stubbed tokenizers. GitHub Actions runs lint and tests, and a separate workflow builds container images for GHCR. The Docker runtime uses a non-root user.

Scope & ongoing work

Verified client support is Claude Code CLI. Claude token counts use the Anthropic API when configured and fall back to a labeled approximation otherwise. Pricing is a manually maintained table and may drift.
