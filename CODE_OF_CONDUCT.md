# Code of Conduct

Welcome to my GitHub Portfolio.

This space represents my professional work and projects in software testing, development, and data engineering. All interactions here should remain respectful, professional, and constructive.

## Principles
- Communicate with respect and courtesy.  
- Provide feedback that is helpful and relevant.  
- Avoid discriminatory or offensive behavior.  
- Follow ethical and legal standards in any shared code or contributions.  
- Support accessibility and inclusivity in all shared content.

## Accessibility Commitment
This portfolio adheres to **WCAG Level A** accessibility standards to promote inclusivity and equal access for all users.

## Enforcement
Any violation of these guidelines may result in restricted access or removal of interactions from this repository.  

Thank you for maintaining a professional and respectful environment.
