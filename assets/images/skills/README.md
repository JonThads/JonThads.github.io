# Skill-card artwork

Local SVGs are used inside logo-then-name skill cards. Visible names provide the accessible label; adjacent images have empty alternative text to avoid reading the same name twice. White icon tiles retain the original logo colors in every theme.

Sources and file SHA-256 hashes are recorded in `sources.json`:

- Devicon: <https://github.com/devicons/devicon>, MIT license retained in `LICENSE-devicon.txt`.
- Simple Icons: <https://github.com/simple-icons/simple-icons>, CC0 license retained in `LICENSE-simple-icons.txt`. Legacy Microsoft and OpenAI marks come from release 11.15.0; other marks were downloaded from the current repository on 9 November 2026. The downloaded SVGs are vendored; no runtime CDN is used.
- Allure Report: official sign from <https://allurereport.org>.
- DeepEval: official site icon from <https://deepeval.com>.
- axe-core uses its maker Deque's official site icon from <https://www.deque.com/axe/axe-core/>.
- Newman uses the Postman mark; its official repository also identifies itself using Postman artwork: <https://github.com/postmanlabs/newman>.
- Docker Compose, GitHub Container Registry, sentence-transformers, tiktoken, and Anthropic SDK use their parent technology, organization, or ecosystem mark. pgvector and REST APIs use concept icons.
- Nine existing roadmap tool images are reused from `../tools/`; their provenance is recorded there.

`concept-*.svg` files are original line icons made for this portfolio. They represent QA practices, support, retrieval, and delivery concepts that do not have product logos. They are illustrations, not official certifications or organization marks.

Product names and marks identify the tools; they do not imply endorsement or affiliation. Brand ownership remains with the respective owners. No third-party JavaScript or tracking resources are included with these images.
